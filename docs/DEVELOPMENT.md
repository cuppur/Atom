## 实现

- `src/main.ts` 管理 Electron 生命周期、IPC 和 Windows 安全存储。渲染器禁止 Node 集成，并使用隔离的 preload、CSP 和固定的本地资源协议。
- `src/models.ts` 负责供应商适配与用量计算，`src/engine.ts` 负责循环、权限、暂停、追加指令、阶段推进和预算。`src/context.ts` 负责估算和保持工具调用记录完整的历史切分。
- `src/workspace.ts`、`src/processes.ts`、`src/network.ts` 和 `src/extensions.ts` 实现工作区、终端与 Git、网络、技能和 MCP。原生工具使用 Zod 校验输入。
- `src/store.ts` 通过 SQLite WAL 保存项目、配置、历史、过程日志和检查点。工具执行前保存发起状态，结束后提交结果。重启时把已发起但未确认结果的操作标为待核对。
- `src/sidebar.tsx` 提供按项目分组、快速搜索、置顶、重命名和可恢复归档，当前会话选择一并持久化。`src/telemetry.ts` 从流式增量计算当前速度和用量估算，最后使用供应商用量结算。`src/statusbar.tsx` 显示缓存命中率和上下文占用。
- `Registry`、`ToolContext` 和可注入的 `StreamModel` 为插件、子 Agent 或多模型路由保留接入点。0.1.0 聚焦单 Agent。

## 0.6.0 目标模式与 Agent 提问

目标模式沿用任务计划、权限和预算体系。普通文本响应触发框架继续请求。`finish_goal` 在待执行、进行中或受阻步骤仍存在时拒绝登记达成，模型需提供验收依据。遇到阻塞可记录原因并暂停。过多无工具回复触发异常停止，可恢复。

`ask_user` 在所有运行模式可用。Agent 的问题保存在当前任务中，GUI 提示等待回答。发送答案会恢复原任务并沿用原模型、计划、权限与预算。询问不替代权限审批。

类型检查、16 项核心回归及源码版 Electron 回归通过，涵盖提前汇报、拒绝提前登记达成、阻塞、提问后重启以及回答后沿原计划完成。

真实 DeepSeek 流式测试在隔离目录成功向用户确认输出文件名。回答后继续原目标，写入并读回 `sum.txt`，独立核对文件内容为 `23`。

## 0.7.0 执行毅力

以独立验收判断拦截三种任务模式的结束。验收器收到原始任务、修订、计划、候选答复、工具结果和受权限限制的有限文件证据。结构化结论决定完成、继续或暂停。验收失败的剩余事项固定在后续执行上下文中。每轮结论、请求上下文和计量独立记录。连续未取得新工具证据的验收继续轮受限，权限不由验收器改变。

相关机制参考 [Claude Code Goal](https://code.claude.com/docs/en/goal)、[Stop Hook](https://code.claude.com/docs/en/hooks)、[Anthropic 长时任务框架](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents)与[生成和验收分工](https://www.anthropic.com/research/harness-design-long-running-apps)。

类型检查、20 项核心回归与源码版桌面回归通过。覆盖普通执行提前汇报、真实命令失败后修复并重跑、独立模型及推理强度分离、简单问答、关闭验收、Token 预算、验收格式错误、上下文压缩以及受阻记录。

真实 DeepSeek 在普通执行模式下完成提问、用户回答、写入和读回 `sum.txt`，随后通过独立验收调用。Windows 10 安装版 0.7.0 通过桌面回归。
