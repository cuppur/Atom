# Atom

Atom 是 Windows 桌面端单 Agent 框架。项目栏可切换项目视图和最近会话。长期记忆和设置位于工作区顶部。对话中的文件变更摘要可按需打开检查器，查看任务进度、差异和进程输出。

当前版本为 **0.8.0 验收候选版**。本地回归、桌面实跑和 Windows x64 安装包验证见 [开发与验收记录](docs/DEVELOPMENT.md)。

## 安装与运行

- 从源码打包后，运行 `release/Atom Setup 0.8.0.exe` 为当前 Windows 用户安装。安装后可双击桌面上的「Atom」，也可在开始菜单搜索「Atom」。直接运行解包版时使用 `release/win-unpacked/Atom.exe`。
- 打开或新建一个本地项目。从输入框右侧的模型菜单进入「管理 API」，选择供应商并保存配置。模型菜单可测试当前模型并切换模型。模型按钮左侧可分别选择推理强度和执行毅力。上下文圆环内保留 300k、600k、900k 档位，受供应商能力和模型配置限制，调整用于下一次任务。
- 「＋」可选择 PNG、JPEG、WebP 图片，也可在输入区直接粘贴截图。图片可从项目外选择，文本附件仍限定在工作区。发送前可预览和移除，发送后随本地会话保存。每次最多 4 张、单张不超过 10 MB、1600 万像素。图片需使用视觉模型，DeepSeek Flash 已实测，DeepSeek V4 Pro 会提示切换。图片会随执行请求和独立验收请求发送给各自配置的模型。
- 左栏按项目组织会话。按 `Ctrl+N` 在当前项目新建会话，按 `Ctrl+K` 搜标题、项目和对话正文。会话菜单支持置顶、重命名和归档。正在运行的任务可确认暂停后归档，随后从「已归档」恢复。
- 使用 DeepSeek 时可以选择预设的 `deepseek-flash` 和 `https://api.deepseek.com`，在应用的密码输入框填写有效密钥。密钥使用 Windows 加密存储，发送到配置的服务域名。
- 按 Enter 发送，Shift+Enter 换行。中文输入法正在组词或选词时，Enter 交给输入法处理。
- 新会话的任务权限默认选择「完全访问权限」，工具无需逐项确认。输入区也可切换为「按规则审批」。显式禁止规则、内置文件工具的路径限制及长期记忆写入确认仍生效。继续已暂停的任务会沿用它启用时的权限档位。
- 多步骤任务会由 Agent 自动拆成计划，显示在对话和检查器的「任务」页。步骤可显示待执行、进行中、已完成、受阻或已跳过，暂停和重启后仍可查看。简单问答可以直接完成。
- 「持续迭代」依次执行开发、测试、审查、修复、回归测试。回归失败会回到修复阶段。测试和回归若要登记通过，需要在该阶段先实际运行一个成功退出的验证命令。
- 「目标模式」持续推进输入的目标。普通进度汇报会触发继续执行，结束时需要提交具体的验收依据，清单也必须收尾。真实阻塞可暂停并说明原因，任务仍受权限、时间、费用和请求次数限制。验收依据由模型填写，可通过工具记录和实际产物复核。
- 各运行模式下，Agent 遇到必须由用户决定的问题可以主动提问。输入区上方显示问题，回答后沿用原任务、模型与计划继续。问题和待执行状态会保存，重启后仍可回答。

支持 OpenAI Responses、Anthropic Messages、Gemini、OpenAI-compatible Chat Completions 及 DeepSeek 配置。推理选项需要目标模型支持。

状态栏实时显示生成速率、输入和输出 Token、缓存命中率，以及上下文使用量、上限和使用率。流式期间的计数与速率带 `≈`，请求结束后用供应商返回的 Token 更新，最终速率用输出 Token 与请求总耗时计算。缓存命中率采用最近已结算请求的缓存读取 Token 除以输入 Token。悬停可查看会话累计与原始用量。字段缺失时显示 `—`，部分请求缺失时用 `+` 标记已知小计。

用量价格按每百万 Token 填写。成本预算使用估算和供应商回报逐步控制，单次请求结算可能超过预估。

### 执行毅力

从模型按钮左侧的「毅力」选择关闭、标准、高或极高。默认标准，全局保存。标准检查必要交付，高档要求核对验证结果，极高档进一步检查与需求相关的边界与失败路径。关闭后跳过独立验收。「推理」选择器单独设置模型推理强度。

普通执行、目标模式和持续迭代都可使用。框架在准备结束时发起独立验收请求，检查原需求、更新、工具记录以及可取得的交付证据。验收未通过时自动将剩余事项交回执行模型。有实际阻塞时暂停，可发送补充信息继续。对话与「检查器 → 任务」可展开验收结论，验收请求也会显示在请求上下文中。

「执行与权限」可指定已保存的独立验收模型，默认使用执行模型进行一次独立调用。选择另一模型会将脱敏后的任务说明和验收证据发送至所选供应商。执行、压缩与验收请求都计入任务的 Token、费用、时间和请求次数预算。预算根据请求前估算和供应商结算执行。有效配置会在开始或恢复任务时应用。

### 请求上下文

点击状态栏的「上下文」，或在当前会话输入 `/context`。面板可切换近期请求，按分类筛选并搜索具体内容。可查看指令分段、长期记忆、历史摘要、用户和框架注入消息、模型消息、工具结果以及工具定义。分类 Token 为估算，供应商返回的输入和缓存读取单独显示。

输入框中的上下文圆环打开简要用量浮层，显示用量、估算分类、档位选择和请求明细入口。

请求快照取自模型适配前的输入。每个会话在本机保留最近 20 条请求。超大正文会明确标记裁剪，快照会隐藏可识别的凭据。升级后的新请求开始生成快照，旧版会话仍可继续使用。

## 项目指令与扩展

### 长期记忆

从左侧书本图标打开记忆面板。项目记忆只供当前项目的会话使用，全局记忆供各项目召回。可新建、编辑、搜索、删除和标记优先召回。也可以告诉 Agent「记住这个项目的发布规则」。Agent 只能提议新增项目记忆，确认后才写入。

记忆保存在本机 SQLite。任务开始和推进时会按关键词挑选少量相关笔记，作为参考上下文发送到当前模型。关闭「在任务中使用记忆」可暂停召回和 Agent 写入，面板内仍可手动维护。删除记录会阻止之后召回该条笔记，已经保存在会话历史里的引用仍属于会话历史。

### 指令、技能与工具

- 读取项目根目录的 `AGENTS.md`，支持全局及项目 System Prompt。
- 在项目的 `.agents/skills/<名称>/SKILL.md`、`skills/<名称>/SKILL.md`，或应用数据目录下的 `skills/<名称>/SKILL.md` 放置技能。Agent 先收到技能名称和简介，再通过 `load_skill` 读取全文。
- 在「执行与权限」配置 MCP。支持本地 stdio 与 Streamable HTTP。注册的 stdio 会以当前用户权限启动。MCP 连接配置以 JSON 保存，请勿把密钥写入参数。
- 使用 `src/extensions.ts` 的 `customTools.register()` 在宿主代码中注册类型化工具。工具沿用结构化执行结果和授权流程。

工作区文件工具只操作当前项目下的普通文本文件，主动拦截路径穿越、链接、设备名、常见凭据路径和 Windows 备用数据流。终端与本地 MCP 属于 Windows 用户权限范围。文件工具自动留存变更差异。终端修改可以再用 `git_status`、`git_diff` 检查。

## 从源码运行

需要 Windows x64、Node.js 24.22 或更新版本和 npm。Git 工具及其测试需要可用的 Git for Windows。

```powershell
npm ci
npm run check
npm test
npm run test:desktop
npm start
npm run package:win
```

可用 `ATOM_SCREENSHOT_DIR` 指定桌面回归截图目录。设置 `ATOM_EXECUTABLE` 后可对解包版运行同一套桌面测试。桌面测试使用本机 SSE 服务和临时项目，实际经过 Electron、API 适配器、文件系统、CMD 和 SQLite。
